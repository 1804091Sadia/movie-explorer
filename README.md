# 🎬 MovieExplorer

A responsive movie and TV show discovery application built with **React.js** and the **TVMaze API**.

Users can browse shows, search for specific titles, and view detailed information in an interactive modal.

## 📌 Features

* 🏠 Responsive Home Page
* 🎬 Movie/TV Show listing
* 🔍 Search shows by title
* ⭐ Display show ratings
* 📅 Display release year
* 🖼️ Show poster images
* 📖 View detailed show information
* 🪟 Interactive details modal
* ❌ Close modal using the close button or outside click
* 📱 Fully responsive design
* ⏳ Loading state
* ⚠️ Error handling

## 🌐 API

This project uses the free [TVMaze API](https://www.tvmaze.com/api).

### Endpoints Used

Get all shows:

```text
https://api.tvmaze.com/shows
```

Search shows:

```text
https://api.tvmaze.com/search/shows?q={query}
```

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/1804091Sadia/movie-explorer.git
```

Navigate to the project directory:

```bash
cd movie-explorer
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```
